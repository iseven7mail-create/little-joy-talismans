# 小確幸守護符｜台灣美食 × 選舉情緒

## [🍡 點這裡立即遊玩](https://iseven7mail-create.github.io/little-joy-talismans/)

**唯有美食，可以退散煩躁。**

翻開三張粉彩刺繡守護符，讓包心粉圓、小籠湯包與其他熟悉的台灣味，陪你把選舉的心事放輕一點。

- 完整 38 張牌卡，每張 JPG 均小於 1 MB。
- 點任一張牌背，三張一起翻開，再選最有感的一張。
- 閱讀美食與情緒故事，選一個暖心小行動。
- 可放大與下載牌卡，並產生自己的回看 PNG 小卡。
- 支援手機與桌面；書寫內容留在本次瀏覽器，不上傳、不永久儲存。

### 網站維護

此儲存庫根目錄就是可發布的靜態網站，不需要安裝依賴或執行建置。GitHub Pages 使用 `main` 分支根目錄，`.nojekyll` 保留所有靜態檔案。

`index.html` 為入口；`app.js` 為互動流程；`data.js` 為 38 張資料；`cards/` 為輕量牌圖；`embroidery.css` 為刺繡樣式。

這是一份以食物與情緒為題的創作，供日常反思與安慰，不替你決定選票。
